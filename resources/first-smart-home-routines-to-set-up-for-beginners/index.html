First smart home routines to set up (for beginners)

Smart home devices can do a lot, which is exactly why it's easy to feel overwhelmed. Start with a few simple routines you'll actually use, using the apps you already have. Leave anything that involves mains wiring to a qualified electrician.

Start with what you own

  • List each device and which app controls it.
  • Check whether your devices can all be added to one main app, such as your speaker's or phone's home app.

Good first routines

  • Lights on at sunset or when you arrive home.
  • A smart plug turning off a lamp or fan at bedtime.
  • A 'goodnight' routine that turns everything off with one command.
  • Lights on gradually in the morning.

Set up one at a time

  • Create one routine, test it for a few days, then add the next.
  • Name devices clearly, such as 'living room lamp', so routines are easy to read.

Keep a record

Write down what each routine does and in which app it lives, so you can change or remove it later.
