Stumped by cryptic crosswords? How the clues actually work

Cryptic clues follow rules. Once you know that every clue is a definition plus wordplay, and learn a handful of clue types, they stop looking random.

Definition plus wordplay

  • Almost every clue has a straight definition of the answer at the start or the end. The rest of the clue is wordplay that builds the same answer another way.

Learn the common types

  • Anagrams: the letters of some words are rearranged. Indicators include "mixed", "broken" and "wild".
  • Hidden words: the answer sits inside the clue. Indicators include "in", "some" and "held by".
  • Charades: the answer is built from pieces joined together.

Learn the abbreviations

  • Setters use standard short forms, such as "note" for a letter from A to G, or "sailor" for AB. Keep a list as you meet them.

Start with quick cryptics

  • Quick cryptic and beginner puzzles use easier clues. Read the answers and explanations the next day for any you missed.

One type at a time

Spend a week spotting just anagrams, then hidden words, then charades. Solving gets much easier once you recognise the type.
