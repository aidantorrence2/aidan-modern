Tagalog verb focus for beginners: when to use -um-, mag- and -in

Tagalog verbs change their form to show which noun in the sentence is the focus (the one marked with ang). This is called focus, and it's the part of Tagalog grammar most learners find hardest. Start with two patterns.

Actor focus: -um- and mag-

  • Use these when the doer is the focus: 'Kumain ang bata ng mangga.' (The child ate a mango.)
  • -um- goes inside the root (kain → kumain); mag- goes in front (luto → nagluto, cooked).
  • Which one a verb takes has to be learned with each verb.

Object focus: -in

  • Use -in when the thing acted on is the focus: 'Kinain ng bata ang mangga.' (The child ate the mango.)
  • Notice that ang moves to the mango, and the child now takes ng.
  • Object focus is very common in everyday Tagalog, often when the object is specific.

Aspect, not tense

  • Tagalog verbs show whether an action is completed, ongoing or not yet started: kumain (ate), kumakain (is eating), kakain (will eat).
  • Learn the three forms of each new verb together.

Practise

  • Take one verb and write it in all three aspects.
  • Write the same sentence in actor focus and object focus.
  • Ask a native speaker which sounds more natural in each situation.
